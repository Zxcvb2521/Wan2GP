# AI Creator Studio — разработка

> **Экспериментальная ветка:** `feature/ai-creator-studio`
>
> Это отдельный слой интерфейса и orchestration поверх WanGP/Wan2GP. Основная цель — превратить набор генеративных движков в компактное Windows-приложение для создания готового контента: изображений, видео, музыки, голоса и затем собирать их в единый результат.

## Концепция

AI Creator Studio не заменяет WanGP как движок генерации. Он использует WanGP как локальный backend и постепенно добавляет собственный пользовательский слой:

```text
AI Creator Studio
        │
        ├── Проекты
        ├── Assets
        ├── AI generation
        ├── Timeline
        └── Final render
                │
                ▼
             WanGP
                │
                ▼
              GPU
```

Основные требования проекта:

- Windows-first;
- отдельное desktop-приложение;
- без Docker;
- без ручного запуска Python;
- без Gradio;
- русский интерфейс;
- локальная работа;
- максимально простой пользовательский интерфейс;
- возможность постепенно подключать разные генеративные движки;
- проектная структура, сохраняющая результаты и настройки;
- путь от текстовой идеи до готового видео/аудио-продукта.

## Текущая архитектура

```text
ai_creator_studio/
├── src/
│   ├── main.tsx
│   └── styles.css
│
├── runtime/
│   └── WanGP/
│       ├── studio_backend.py
│       ├── studio_projects.py
│       ├── studio_timeline.py
│       └── studio_render.py
│
└── projects/
    ├── generated/
    └── data/
```

### `studio_backend.py`

Локальный HTTP bridge на `127.0.0.1`. Он связывает desktop UI с headless WanGP session API и предоставляет приложению понятный API:

- `/health`
- `/models`
- `/models/{model}/schema`
- `/projects`
- `/projects/{id}/assets`
- `/projects/{id}/timeline`
- `/projects/{id}/timeline/items`
- `/projects/{id}/timeline/items/{item}` — изменение клипа;
- `/projects/{id}/render`
- `/generate/image`
- `/jobs/{id}`
- `/jobs/{id}/cancel`
- `/renders/{id}`

Для Timeline изменения нормализуются: `start` не может быть отрицательным, длительность не может быть меньше 0.05 секунды, а общая длина Timeline пересчитывается автоматически.

### `studio_projects.py`

SQLite-хранилище проектов и Assets. Результаты генерации и итоговый MP4 записываются в проект, поэтому проект постепенно становится самостоятельным контейнером созданного контента.

### `studio_timeline.py`

Легковесное persistent-хранилище Timeline. Timeline хранится отдельно от React UI и содержит проект, FPS, длительность и клипы. Теперь хранилище поддерживает изменение и удаление отдельных клипов через стабильные идентификаторы.

### `studio_render.py`

Минимальный локальный FFmpeg renderer. На текущем этапе он умеет собрать последовательность изображений/видео и смешать дорожки голоса/музыки в MP4. Это сознательно небольшой первый слой: эффекты, переходы и сложный монтаж будут добавляться поверх существующего формата Timeline.

## Экспорт

Пользователь выбирает проект → открывает Timeline → нажимает **«Экспорт MP4»**.

```text
Project Timeline
      ↓
POST /projects/{id}/render
      ↓
background render job
      ↓
FFmpeg
      ↓
projects/generated/{project_id}/...
      ↓
Asset проекта
```

Экспорт выполняется в фоне, поэтому интерфейс не должен зависать во время рендера.

## Важный принцип

**AI Creator Studio — это не ещё один тяжёлый интерфейс поверх Gradio.**

Цель — сделать небольшой, быстрый и понятный desktop-инструмент, где сложность WanGP, моделей, Python, CUDA и отдельных генераторов скрыта от пользователя настолько, насколько это возможно без потери контроля для продвинутого пользователя.

## Ветка разработки

Все изменения этой концепции на текущем этапе выполняются в:

`feature/ai-creator-studio`

Основная ветка WanGP не должна изменяться этой экспериментальной разработкой до момента, когда desktop-слой будет достаточно стабилен для объединения.
