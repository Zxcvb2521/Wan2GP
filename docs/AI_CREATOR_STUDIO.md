# AI Creator Studio — разработка

> **Экспериментальная ветка:** `feature/ai-creator-studio`
>
> Это отдельный слой интерфейса и orchestration поверх WanGP/Wan2GP. Основная цель — превратить набор генеративных движков в компактное Windows-приложение для создания готового контента: изображений, видео, музыки, голоса и затем собирать их в единый результат.

## Концепция

AI Creator Studio не заменяет WanGP как движок генерации. Он использует WanGP как локальный backend и постепенно добавляет собственный пользовательский слой:

```text
AI Creator Studio
        │
        ├── Проекты
        ├── Assets
        ├── AI generation
        ├── Timeline
        └── Final render
                │
                ▼
             WanGP
                │
                ▼
              GPU
```

Основные требования проекта:

- Windows-first;
- отдельное desktop-приложение;
- без Docker;
- без ручного запуска Python;
- без Gradio;
- русский интерфейс;
- локальная работа;
- максимально простой пользовательский интерфейс;
- возможность постепенно подключать разные генеративные движки;
- проектная структура, сохраняющая результаты и настройки;
- путь от текстовой идеи до готового видео/аудио-продукта.

## Текущая архитектура

```text
ai_creator_studio/
├── src/
│   ├── main.tsx
│   └── styles.css
│
├── runtime/
│   └── WanGP/
│       ├── studio_backend.py
│       └── studio_timeline.py
│
└── projects/
    ├── generated/
    └── data/
```

### `studio_backend.py`

Локальный HTTP bridge на `127.0.0.1`. Он связывает desktop UI с headless WanGP session API и предоставляет приложению понятный API:

- `/health`
- `/models`
- `/models/{model}/schema`
- `/projects`
- `/projects/{id}/assets`
- `/projects/{id}/timeline`
- `/projects/{id}/timeline/items`
- `/generate/image`
- `/jobs/{id}`
- `/jobs/{id}/cancel`

### `studio_timeline.py`

Легковесное persistent-хранилище Timeline. На текущем этапе используется JSON внутри локального каталога проекта. Архитектура специально отделена от UI, чтобы позднее заменить хранилище на SQLite/единую project database без переписывания Timeline-компонента.

## План ближайшей разработки

### Этап 1 — Timeline 2.0

- drag & drop клипов;
- изменение длительности;
- перемещение по времени;
- удаление клипов;
- дублирование;
- редактирование названия;
- отображение thumbnail;
- нормальная временная шкала;
- сохранение всех изменений.

### Этап 2 — Media Engine

Создать локальный FFmpeg-слой, который сможет читать Timeline и собирать настоящий результат:

```text
Timeline
   ↓
FFmpeg graph
   ├── video
   ├── voice
   ├── music
   ├── image
   └── audio mixing
   ↓
MP4 / WebM / WAV / MP3
```

### Этап 3 — Голос и музыка

Подключить единый интерфейс для локальных и доступных через WanGP движков:

- TTS;
- voice conversion;
- speech generation;
- music generation;
- sound effects.

### Этап 4 — AI Director

Пользователь сможет дать одну задачу вроде:

> «Создай двухминутный мультфильм про Макса, который нашёл волшебную коробочку».

Studio должна постепенно превращать её в:

```text
идея
 ↓
сценарий
 ↓
сцены
 ↓
промпты
 ↓
изображения / видео
 ↓
голоса
 ↓
музыка
 ↓
Timeline
 ↓
рендер
 ↓
готовый MP4
```

## Важный принцип

**AI Creator Studio — это не ещё один тяжёлый интерфейс поверх Gradio.**

Цель — сделать небольшой, быстрый и понятный desktop-инструмент, где сложность WanGP, моделей, Python, CUDA и отдельных генераторов скрыта от пользователя настолько, насколько это возможно без потери контроля для продвинутого пользователя.

## Ветка разработки

Все изменения этой концепции на текущем этапе выполняются в:

`feature/ai-creator-studio`

Основная ветка WanGP не должна изменяться этой экспериментальной разработкой до момента, когда desktop-слой будет достаточно стабилен для объединения.
